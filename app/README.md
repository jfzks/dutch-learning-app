# Dutch — learning tool

Single-file HTML app that drills you on the Dutch course materials in this folder.

## How to open

Either:

1. **Double-click** `index.html` and it opens in your default browser. Works fully offline.
2. Or, from the parent folder, run `python3 -m http.server 8765 --directory app` and open `http://localhost:8765/`. (Recommended on Safari, which is sometimes stricter about local files.)

No build step, no internet, no backend.

## Pages

- **Home** — pick a drill. Filter by woordenlijst (9–14), lesson list (Les 17 Aug, Les 23 Aug, …) and/or grammar topic; choose Easy / Medium / Hard.
- **Grammar** — quick reference for every grammar topic extracted from the source files.
- **Verbs** — the eDHfA1 list of 141 irregular verbs.
- **Add** — type a new word or sentence; it's saved to your browser and merged into all drills.
- **Backup** — export / import your progress + custom items as JSON. Reset is here too.

## Drills

| Drill | What you do |
|---|---|
| Flashcards NL→EN / EN→NL | Tap to flip; rate yourself. |
| Translate EN→NL / NL→EN | Type the translation; checks accept synonyms separated by `/` or `,`. |
| De of het? | Pick the article for the noun. |
| Conjugate verb | Write the perfectum / imperfectum form for a given person. |
| Pingpongen — perfectum / imperfectum | Rewrite a present-tense prompt in the target tense. |
| Word-order builder | Drag tiles into the right order (V2, inversion, subclause, etc.). |
| Cloze (invultekst) | Fill the missing word from a grammar example. |
| Dictation | The browser speaks the sentence in Dutch; you type what you hear. |
| Make a sentence | Given 2–3 words (and on Hard, a time expression), write a full sentence. |
| Mixed quiz | A random drill each round. |
| Review mistakes | Replays items you recently got wrong as flashcards. |

Difficulty:
- **Easy** — single concept, words only.
- **Medium** — adds sentence-level translations and a second tense in conjugation.
- **Hard** — combines features: more words, more tenses, present-modal conjugation.

## Spaced repetition

Each item has a Leitner box (0–5). Boxes correspond to review intervals 0/1/2/4/8/16 days. Drills prioritise items that are due. Items you fail drop a box and land in **Review mistakes**.

## Adding content

The Add page accepts:

- **Words**. Prefix with `de` or `het` to set the article. Example: `de bakker` → `baker`.
- **Sentences**. Add an optional translation and comma-separated tags (e.g. `perfectum, separable, modal`).

Custom items live in `localStorage` and never touch the original JSON files. Export them via the Backup page so they survive a browser reset.

## Where data lives

| What | Where |
|---|---|
| Course content | `app/data/words/*.json`, `app/data/grammar/*.json`, `app/data/verbs/*.json`, `app/data/sentences.json` |
| Lesson notes typed up by hand | `extraction/lessons/<YYYY-MM-DD>.tsv` → `app/data/words/lesson-<YYYY-MM-DD>.json` |
| Bundled for the browser | `app/data.js` (auto-generated by `extraction/build_data_js.py`) |
| Your progress + custom items | Browser `localStorage` under the key `dutch-app-v1` |
| Source PDFs / DOCX | One folder up, in `Grammar/`, `Wordlists/`, `Homework/`, `Other Materials/` |

## Re-extracting / regenerating data

If you change the source files in `Grammar/`, `Wordlists/`, etc.:

```bash
cd "Dutch - learnings"
python3 extraction/dump_text.py            # raw text dump
python3 extraction/parse_wordlists.py      # words → app/data/words/*.json
python3 extraction/parse_verbs.py          # irregular verbs
python3 extraction/parse_sentences.py      # sentences from homework
python3 extraction/add_lesson_words.py     # lesson notes → app/data/words/lesson-*.json + _all.json
python3 extraction/build_data_js.py        # bundle into app/data.js
```

`parse_wordlists.py` rewrites `_all.json` from the course wordlists only, so run
`add_lesson_words.py` after it to fold the lesson lists back in.

The grammar JSONs (`app/data/grammar/*.json`) are hand-curated — edit them by hand.

## Adding a lesson's words

Type the words into `extraction/lessons/<YYYY-MM-DD>.tsv`, one per line:

```
nl<TAB>en<TAB>pos
de gelegenheid	occasion	noun
kroegen (de kroeg)	pubs
klagen over	to complain about	verb
```

`pos` (`noun` / `verb` / `phrase` / `other`) is optional — leave it off and it's
inferred, same rules as the course wordlists: a `de`/`het` prefix makes a noun,
`plural (de singular)` keys the entry on the singular, `zich X` a reflexive verb.
Then:

```bash
python3 extraction/add_lesson_words.py     # or pass specific dates: … 2026-08-23
python3 extraction/build_data_js.py
```

Words whose Dutch head already exists in another list are skipped and reported,
so re-running is safe and lesson lists never duplicate the course vocabulary.

## Known gaps in the source extraction

- **Wordlists** were originally tabular but got flattened to plain paragraphs in the .docx. Most splits are right; ambiguous ones (e.g. `kom binnen`, `van harte gefeliciteerd`) are patched via `extraction/wordlist_overrides.json`.
- **Homework sentence extraction** is heuristic — some lines that are rule explanations get pulled in alongside actual Dutch sentences. They're tagged but not filtered out, and may show up in dictation/word-order drills.
- **Tags on harvested sentences** are heuristic ("perfectum", "subclause", etc.) and occasionally wrong. The app trusts them only for filtering, not grading.

## Keyboard shortcuts

- **Enter** in any input — submit answer.
- During flashcards, click the card to flip; use the buttons to record the result.
