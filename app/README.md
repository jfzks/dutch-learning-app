# Dutch — learning tool

Single-file HTML app that drills you on the Dutch course materials in this folder.

## How to open

Either:

1. **Double-click** `index.html` and it opens in your default browser. Works fully offline.
2. Or, from the parent folder, run `python3 -m http.server 8765 --directory app` and open `http://localhost:8765/`. (Recommended on Safari, which is sometimes stricter about local files.)

No build step, no internet, no backend.

## Pages

- **Home** — pick a drill. Filter by wordlist (course lists WL 9–14, plus the Notitieboek lists harvested from the Pages notebook) and/or grammar topic.
- **Grammar** — quick reference for every grammar topic extracted from the source files.
- **Verbs** — the eDHfA1 list of 141 irregular verbs.
- **Add** — type a new word or sentence; it's saved to your browser and merged into all drills.
- **Backup** — export / import your progress + custom items as JSON. Reset is here too.

## Drills

| Drill | What you do |
|---|---|
| Flashcards NL→EN / EN→NL | Tap to flip; rate yourself. |
| Translate EN→NL / NL→EN | Type the translation; checks accept synonyms separated by `/` or `,`. |
| De of het? | Pick the article for the noun. |
| Conjugate verb | Write the perfectum / imperfectum form for a given person. |
| Pingpongen — perfectum / imperfectum | Rewrite a present-tense prompt in the target tense. |
| Word-order builder | Drag tiles into the right order (V2, inversion, subclause, etc.). |
| Cloze (invultekst) | Fill the missing word from a grammar example. |
| Dictation | The browser speaks the sentence in Dutch; you type what you hear. |
| Make a sentence | Given 2–3 words (and on Hard, a time expression), write a full sentence. |
| Mixed quiz | A random drill each round. |
| Review mistakes | Replays items you recently got wrong as flashcards. |

Difficulty:
- **Easy** — single concept, words only.
- **Medium** — adds sentence-level translations and a second tense in conjugation.
- **Hard** — combines features: more words, more tenses, present-modal conjugation.

## Spaced repetition

Each item has a Leitner box (0–5). Boxes correspond to review intervals 0/1/2/4/8/16 days. Drills prioritise items that are due. Items you fail drop a box and land in **Review mistakes**.

## Adding content

The Add page accepts:

- **Words**. Prefix with `de` or `het` to set the article. Example: `de bakker` → `baker`.
- **Sentences**. Add an optional translation and comma-separated tags (e.g. `perfectum, separable, modal`).

Custom items live in `localStorage` and never touch the original JSON files. Export them via the Backup page so they survive a browser reset.

## Where data lives

| What | Where |
|---|---|
| Course content | `app/data/words/woordenlijst-*.json`, `app/data/grammar/*.json`, `app/data/verbs/*.json`, `app/data/sentences.json` |
| Notebook vocabulary | `app/data/words/notitieboek-YYYY-MM.json` (from the Pages notebook — see below) |
| Flat aggregate for greps | `app/data/words/_all.json` (derived; rebuilt by `build_data_js.py`, never edit by hand) |
| Bundled for the browser | `app/data.js` (auto-generated by `extraction/build_data_js.py`) |
| Your progress + custom items | Browser `localStorage` under the key `dutch-app-v1` |
| Source PDFs / DOCX | One folder up, in `Grammar/`, `Wordlists/`, `Homework/`, `Other Materials/` |

## Re-extracting / regenerating data

If you change the source files in `Grammar/`, `Wordlists/`, etc.:

```bash
cd "Dutch - learnings"
python3 extraction/dump_text.py            # raw text dump
python3 extraction/parse_wordlists.py      # words → app/data/words/*.json
python3 extraction/parse_verbs.py          # irregular verbs
python3 extraction/parse_sentences.py      # sentences from homework
python3 extraction/parse_notebook.py       # notebook words → app/data/words/notitieboek-*.json
python3 extraction/build_data_js.py        # bundle into app/data.js + refresh words/_all.json
```

The grammar JSONs (`app/data/grammar/*.json`) are hand-curated — edit them by hand.

Always finish with `build_data_js.py`. Nothing the app reads comes from the JSON
files directly — `index.html` loads only `app/data.js` — so a data edit that isn't
followed by a rebuild has no effect in the browser.

## The Notitieboek lists

`app/data/words/notitieboek-YYYY-MM.json` comes from the personal Pages notebook
("Dutch A1/A2"), which is a stack of dated two-column tables plus inline `nl - en`
notes. Two files drive it:

- `extraction/notebook_raw.json` — a verbatim dump of the notebook: every table
  row and inline pair exactly as typed, misspellings included. Never edit this by
  hand; re-dump it if the notebook changes.
- `extraction/notebook_overrides.json` — the curation layer, keyed `<date>||<raw NL cell>`.
  This is where a Dutch typo gets corrected, a missing English gloss gets filled in,
  a duplicate gets dropped, or two glosses of the same word get merged. Every entry
  carries a `why` so the change is auditable against the original notebook.

`parse_notebook.py` applies the overrides, derives `pos` / `article` / `lemma` /
`infinitive` from the corrected Dutch, merges same-headword duplicates within a
month, and reports any override key that matched nothing (a typo in the key).

## Answer checking

`acceptableAnswers()` accepts more than the literal stored string:

- `/`- and comma-separated alternatives, as before.
- The headword with its parenthetical removed, and the parenthetical itself when it
  looks like a lemma — so `geprobeerd (proberen)` accepts `geprobeerd` *and*
  `proberen`, and `neighbour (f)` accepts `neighbour`. Longer usage notes (anything
  containing `=` or `…`, or more than two words) are shown but never demanded.
- Any other translation the dataset records for the same prompt. Two lists can gloss
  one word differently — `kapot` is "broken" in WL 10 and "open" in WL 9 — and both
  now count as correct whichever card comes up.

## Known gaps in the source extraction

- **Wordlists** were originally tabular but got flattened to plain paragraphs in the .docx. Most splits are right; ambiguous ones (e.g. `kom binnen`, `van harte gefeliciteerd`) are patched via `extraction/wordlist_overrides.json`. The column-split artefacts this produced (`het | cadeautje`, `kom | … verder`, `het | wedstrijdje`, `in | orde maken fix`) are fixed in `app/corrections-*.json`.
- **The notebook** records a learner's own spelling, so the raw dump contains Dutch typos. They are corrected in `extraction/notebook_overrides.json` rather than in the dump. Three rows were left out entirely because the English cell was empty and the Dutch was too ambiguous to reconstruct (`het staat blauw`, `beroemen`, and a stray note row); one pair, `waaier` → "flyer", is glossed as "hand fan" but may have been meant as `de folder`.
- **Homework sentence extraction** is heuristic — some lines that are rule explanations get pulled in alongside actual Dutch sentences. They're tagged but not filtered out, and may show up in dictation/word-order drills.
- **Tags on harvested sentences** are heuristic ("perfectum", "subclause", etc.) and occasionally wrong. The app trusts them only for filtering, not grading.
