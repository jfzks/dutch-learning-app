# Dutch — flashcards

Single-file HTML app that drills the Dutch vocabulary in this folder as
tap-to-flip flashcards.

## How to open

Either:

1. **Double-click** `index.html` and it opens in your default browser. Works fully offline.
2. Or, from the parent folder, run `python3 -m http.server 8765 --directory app` and open `http://localhost:8765/`. (Recommended on Safari, which is sometimes stricter about local files.)

No build step, no internet, no backend.

## How it works

1. Pick a **direction** — Dutch → English or English → Dutch.
2. Pick **how many words** — 10, 20, 30, 40, or 50.
3. That many words are drawn at random from the whole deck (every wordlist
   pooled together) and shuffled into a session.

On each card: tap it (or press **Space** / **Enter**) to flip between the two
languages. Move with **Prev** / **Next** (or the **←** / **→** keys), and tap
**🔊** to hear the Dutch pronounced by the browser's built-in voice. Nouns show
their article (`de` / `het`) in red. At the end you can shuffle a fresh batch or
change the count.

Your chosen direction and count are remembered in the browser between visits;
nothing else is stored, and there's no scoring or spaced repetition — every
session is a fresh random draw.

## Where data lives

| What | Where |
|---|---|
| Vocabulary shown in the app | `app/data/words/*.json` |
| Course content (also bundled, unused by the app) | `app/data/grammar/*.json`, `app/data/verbs/*.json`, `app/data/sentences.json` |
| Lesson notes typed up by hand | `extraction/lessons/<YYYY-MM-DD>.tsv` → `app/data/words/lesson-<YYYY-MM-DD>.json` |
| Bundled for the browser | `app/data.js` (auto-generated by `extraction/build_data_js.py`) |
| Your direction + count preference | Browser `localStorage` under the key `dutch-flashcards` |
| Source PDFs / DOCX | One folder up, in `Grammar/`, `Wordlists/`, `Homework/`, `Other Materials/` |

The flashcards only read `window.DATA.words`. The grammar, verb and sentence
JSONs are still generated and bundled (so the data pipeline is unchanged), but
the current app doesn't use them.

## Re-extracting / regenerating data

If you change the source files in `Grammar/`, `Wordlists/`, etc.:

```bash
cd "Dutch - learnings"
python3 extraction/dump_text.py            # raw text dump
python3 extraction/parse_wordlists.py      # words → app/data/words/*.json
python3 extraction/parse_verbs.py          # irregular verbs
python3 extraction/parse_sentences.py      # sentences from homework
python3 extraction/add_lesson_words.py     # lesson notes → app/data/words/lesson-*.json + _all.json
python3 extraction/build_data_js.py        # bundle into app/data.js
```

`parse_wordlists.py` rewrites `_all.json` from the course wordlists only, so run
`add_lesson_words.py` after it to fold the lesson lists back in.

The grammar JSONs (`app/data/grammar/*.json`) are hand-curated — edit them by hand.

## Adding a lesson's words

Type the words into `extraction/lessons/<YYYY-MM-DD>.tsv`, one per line:

```
nl<TAB>en<TAB>pos
de gelegenheid	occasion	noun
kroegen (de kroeg)	pubs
klagen over	to complain about	verb
```

`pos` (`noun` / `verb` / `phrase` / `other`) is optional — leave it off and it's
inferred, same rules as the course wordlists: a `de`/`het` prefix makes a noun,
`plural (de singular)` keys the entry on the singular, `zich X` a reflexive verb.
Then:

```bash
python3 extraction/add_lesson_words.py     # or pass specific dates: … 2026-08-23
python3 extraction/build_data_js.py
```

Words whose Dutch head already exists in another list are skipped and reported,
so re-running is safe and lesson lists never duplicate the course vocabulary.

## Known gaps in the source extraction

- **Wordlists** were originally tabular but got flattened to plain paragraphs in the .docx. Most splits are right; ambiguous ones (e.g. `kom binnen`, `van harte gefeliciteerd`) are patched via `extraction/wordlist_overrides.json`. A few malformed one-word entries are filtered out at load time by the app.

## Keyboard shortcuts

- **Space** / **Enter** — flip the current card.
- **←** / **→** — previous / next card.
